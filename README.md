# COM731 Hotel Booking Analysis System

This project implements the COM731 Software Project using the supplied hotel booking dataset.

## Files
- `main.ipynb` – main Jupyter Notebook entry point.
- `data_loader.py` – loads CSV data using both `csv.reader()` and `pandas.read_csv()`.
- `retrieval.py` – Task B list-based retrieval functions.
- `analysis.py` – Task C Pandas analysis functions.
- `visualisation.py` – Task D Matplotlib visualisations.
- `user_interface.py` – main menu and submenus.
- `hotel_booking.csv` – supplied dataset.

## Running
Keep all files in the same directory. Open `main.ipynb`, run all cells, enter `hotel_booking.csv` when requested, and use the menu to select tasks.

Python 3.10+ is recommended. Required packages are pandas and matplotlib.
